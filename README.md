# 📊 E-Commerce Sales Dashboard

Interactive dashboard built with **Streamlit** to analyze E-Commerce sales data.  
This project is part of a **Data Analysis submission**, focusing on sales trends, customer behavior, and business insights.

## 🧠 Features
- Sales overview and trends
- Monthly order analysis
- Revenue insights
- Data visualization using charts
- Interactive filters

---

## 🛠️ Tech Stack
- **Python**
- **Streamlit**
- **Pandas**
- **Matplotlib & Seaborn** 

---

## ⚙️ How to Run Locally

1. Clone repository
   ```bash
   git clone https://github.com/raihanmeintaro/E-Commerce-Sales.git
   cd E-Commerce-Sales/Dashboard
2. Install Dependencies
   ```bash
   pip install -r requirements.txt
4. Run Streamlit App
   ```bash
   streamlit run dashboard.py
